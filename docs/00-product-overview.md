# Product Overview

SafeTunnel is a privacy-focused VPN application for Android with a Spring Boot backend utilizing WireGuard tunnels.

## Vision
Build a technically sound, secure, and maintainable VPN product suitable for eventual Google Play Store publication.

## Core Features (V1)
- User registration and authentication
- VPN server selection
- WireGuard-based VPN connection
- Connection statistics (upload/download, duration)
- Session history
- Basic settings and profile management
